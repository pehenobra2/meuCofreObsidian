## 1. Atalhos essenciais 🚀

- Abrir arquivo ➡️ `Ctrl + Shift + R`
- Abrir Tipo (Classe, interface) ➡️ `Ctrl + Shift + T`
- Salvar tudo ➡️ `Ctrl + Shift + S`
- Fechar aba atual ➡️ `Ctrl + w`
- Fechar todas as abas ➡️ `Ctrl + Shift + w`
- Alternar entre arquivos abertos ➡️ `Ctrl + F6`

---

## 2. Edição de código 📝

- Formatar código ➡️ `Ctrl + Shift + F`
- Renomear variável, Método ou classe ➡️ `Alt + Shift + R`
- Comentar linha ➡️ `Ctrl + /`
- Comentar Bloco ➡️ `Ctrl + Shift + /` 
- Descomentar bloco ➡️ `Ctrl + Shift + \`
- Auto complementar código ➡️ `Ctrl + Space`
- Mostrar Documentação (Javadoc) ➡️ `Shift + F2`

---

## 3. Navegação rápida 📂

- Ir para linha específica ➡️ `Ctrl + L`
- Voltar para última posição ➡️ `Alt + ⬅️` 
- Avançar para a posição seguinte ➡️ `Alt + ➡️`
- Ir para a definição de um Método/Classe ➡️ `F3`

---

## 4. Debug 🐞

- Iniciar debug ➡️ `F11`
- Executar até o próximo breakpoint ➡️ `F8`
- Passar para a próxima linha (Step over) ➡️ `F6`
- Entrar no método (Step into) ➡️ `F5`
- Sair do método (Step return) ➡️ `F7`

---

## 5. Refatoração rápida 🔄

- Extrair variável ➡️ `Alt + Shift + L`
- Extrair método ➡️ `Alt + Shift + M`
- Organizar Imports ➡️ `Ctrl + Shift + O`
- Corrigir erros sugeridos ➡️ `Ctrl + 1`

---

## 6. Execução de código ⚡

- Executar programa ➡️ `Ctrl + F11`
- Executar como aplicação Java ➡️ `Alt + Shift + X + J` 
- Parar execução ➡️ `Ctrl + F2`
