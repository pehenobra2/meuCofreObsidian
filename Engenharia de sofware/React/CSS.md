# 📌 Atributos CSS e suas Funções

## 🔹 1. Estilização de Texto
- **color**: Define a cor do texto.  
  - Exemplo: `color: red;`  
- **font-size**: Define o tamanho da fonte.  
  - Exemplo: `font-size: 16px;`  
- **font-weight**: Controla a espessura da fonte (normal, bold, lighter, etc.).  
  - Exemplo: `font-weight: bold;`  
- **font-family**: Define a fonte do texto.  
  - Exemplo: `font-family: Arial, sans-serif;`  
- **text-align**: Define o alinhamento do texto (`left`, `center`, `right`, `justify`).  
  - Exemplo: `text-align: center;`  
- **text-decoration**: Define decoração do texto (sublinhado, riscado, etc.).  
  - Exemplo: `text-decoration: underline;`  
- **letter-spacing**: Define o espaçamento entre letras.  
  - Exemplo: `letter-spacing: 2px;`  

## 🔹 2. Tamanho e Dimensões
- **width**: Define a largura do elemento.  
  - Exemplo: `width: 100px;`  
- **height**: Define a altura do elemento.  
  - Exemplo: `height: 200px;`  
- **max-width** / **max-height**: Define a largura/altura máxima do elemento.  
- **min-width** / **min-height**: Define a largura/altura mínima do elemento.  

## 🔹 3. Espaçamentos
- **margin**: Define o espaçamento externo do elemento.  
  - Exemplo: `margin: 10px;`  
- **padding**: Define o espaçamento interno do elemento.  
  - Exemplo: `padding: 20px;`  
- **border**: Define a borda do elemento (espessura, tipo, cor).  
  - Exemplo: `border: 2px solid black;`  

## 🔹 4. Cores e Fundo
- **background-color**: Define a cor de fundo do elemento.  
  - Exemplo: `background-color: blue;`  
- **background-image**: Define uma imagem de fundo.  
  - Exemplo: `background-image: url('imagem.jpg');`  
- **opacity**: Define a opacidade do elemento (`0` = transparente, `1` = opaco).  
  - Exemplo: `opacity: 0.5;`  

## 🔹 5. Posição e Exibição
- **display**: Define como o elemento será exibido (`block`, `inline`, `flex`, `grid`, etc.).  
  - Exemplo: `display: flex;`  
- **position**: Define o posicionamento do elemento (`relative`, `absolute`, `fixed`, `sticky`).  
  - Exemplo: `position: absolute;`  
- **top / bottom / left / right**: Define a posição do elemento quando `position` é diferente de `static`.  

## 🔹 6. Flexbox e Grid
- **justify-content**: Alinha itens no eixo principal do `flexbox`.  
  - Exemplo: `justify-content: center;`  
- **align-items**: Alinha itens no eixo cruzado do `flexbox`.  
  - Exemplo: `align-items: flex-start;`  
- **grid-template-columns**: Define a estrutura de colunas em um `grid`.  
  - Exemplo: `grid-template-columns: 1fr 2fr;`  

## 🔹 7. Outros
- **visibility**: Controla a visibilidade do elemento (`visible`, `hidden`).  
- **overflow**: Define o comportamento quando o conteúdo excede o tamanho do elemento (`hidden`, `scroll`, `auto`).  
- **cursor**: Define o tipo do cursor ao passar sobre o elemento (`pointer`, `default`, `text`).
