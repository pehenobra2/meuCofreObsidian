## Prática: Projeto MinhasFinanças - Spring boot e React Native

Desenvolver um aplicativo completo de gestão de finanças pessoais, aplicando **boas práticas de arquitetura, segurança e otimização de performance**. O projeto será construído com **Spring Boot no backend e React Native no frontend**, permitindo treinar desde conceitos fundamentais até técnicas avançadas.

✅ **Java Moderno (Java 17+)** – Uso de Streams API, Lambdas, Records e Sealed Classes para processamento eficiente de dados financeiros.  
✅ **JVM Internals** – Otimização de desempenho com ajustes no Garbage Collector e ClassLoaders. 
✅ **Design Patterns** – Implementação de Factory, Builder e Strategy para modularizar regras de negócio.  
✅ **SOLID & Clean Code** – Código bem estruturado e de fácil manutenção.  
✅ **Testes Automatizados** – Testes unitários e de integração com JUnit, Mockito e Testcontainers.  
✅ **Banco de Dados (PostgreSQL)** – Modelagem eficiente, otimização de queries e caching com Redis.  
✅ **Segurança** – Autenticação via JWT/OAuth2, criptografia de dados sensíveis e proteção contra ataques comuns (OWASP Top 10).  
✅ **Performance & Escalabilidade** – Aplicação de caching, balanceamento de carga e boas práticas para alto desempenho.
