
## 1. Atalhos essenciais 🚀

- Abrir comandos rápidos ➡️ `Ctrl + P`
- Criar nova nota ➡️ `Ctrl + N`
- Abrir Arquivo rápido ➡️ `Ctrl + O`
- Alterar modo de edição/visualização ➡️ `Ctrl + E`
- Alterar painel lateral ➡️ `Ctrl + Shift + L`

---

## 2. Organização e Navegação 📂

- Criar o link interno para outra nota ➡️ `[[Nota da nota]]`
- Criar subpáginas (Wikilinks) ➡️ `[[Pasta/nota]]`
- Adicionar tags ➡️ `#tag`
- Adicionar Alias a uma nota ➡️ No frontmatter:
```yaml
---
aliases: [Outro nome]
---
```
- Backlinks (Notas relacionadas)➡️ `Ctrl + Shift + B`

---

## 3. Painel de divisão de janelas 💻

- Dividir tela verticalmente ➡️ `Ctrl + Alt + V`
- Dividir tela horizontalmente ➡️ `Ctrl + Alt + H`
- Alterar entre paineis ➡️ `Ctrl + Tab`

---

## 4. Plugins Nativos Úteis ⚡
- Graph View ➡️ `Ctrl + G` (Mapa de conexões entre notas)
