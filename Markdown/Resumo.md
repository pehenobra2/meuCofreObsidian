
## 1. Títulos
```md
# Título 1
## Título 2
### Título 3
```

## 2. Texto em negrito, itálico e riscado
```md
**Negrito** ou __Negrito__
*Itálico* ou _Itálico_
~~Texto riscado~~
```

## 3. Listas
- **Lista não ordenada** (use `-`, `*` ou `+`):
```md
- Item 1 
- Item 2
```
- **Lista ordenada** (use números seguidos de ponto):
```md
1. Primeiro item
2. Segundo item
```

## 4. Links e imagens
```md
[Texto do link](https://exemplo.com)
![Texto alternativo](https://exemplo.com/imagem.png)
[[linkNota |Link nota]]
```

## 5. Código e blocos de código
- Código inline:
`TESTE`
- Bloco de código
```md
Teste
```

## 6. Citações e Tabelas
- **Citações** (use `>`):
```md
> Isso é uma citação
```
- **Tabela** (use `|` e `-`):
```md
| Nome   | Idade |
|--------|------|
| João   | 25   |
| Maria  | 30   |
```

| Nome  | Idade |
| ----- | ----- |
| João  | 25    |
| Maria | 30    |

## 7. Matemática
```md
$E = mc^2$
```
$E = mc^2$


Ou em bloco:
```md
$$E = mc^2$$
```
